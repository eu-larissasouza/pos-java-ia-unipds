## 🎯 Sobre o Programa

Este repositório reúne os materiais e aprendizados da **Pós-Graduação / Especialização em Engenharia de Software com Java + IA** da UNIPDS.

O programa é dividido em três grandes eixos práticos e teóricos:

* **Ecossistema Enterprise Java Moderno:** Domínio dos fundamentos avançados da linguagem (Collections, Streams, NIO 2), programação assíncrona/reativa (Spring WebFlux, CompletableFuture) e alta performance com **Virtual Threads (Project Loom)** no Quarkus e Spring Boot.


* **Inteligência Artificial Corporativa:** Aplicação de IA generativa e preditiva no mundo corporativo usando Java com **LangChain4j**, arquitetura **RAG** (Retrieval-Augmented Generation), busca vetorial, agentes autônomos e o padrão **MCP (Model Context Protocol)**.


* **Arquitetura, Cloud & Resiliência:** Criação de sistemas distribuídos e escaláveis com **Clean Architecture, DDD, Event-Driven Architecture (Kafka/RabbitMQ)**, além de conteinerização e deploy moderno (**Docker, Kubernetes, AWS**) e práticas rigorosas de testes (**JUnit 5, Testcontainers, ArchUnit**).

## 💡 Como os Estudos são Organizados

* **`docs/` (Conceitos & Decisões):** Focado em registrar dores de mercado, soluções aplicadas e *gotchas* técnicos de cada aula — transformando teoria em material rápido de consulta para entrevistas e desafios de código.


* **`labs/` (Mão na Massa):** Códigos isolados e implementações pontuais de POCs exploradas durante os módulos.


* **Projetos Finais:** Os dois projetos de grande porte da pós possuem **repositórios dedicados e independentes** para compor portfólio profissional em destaque.
